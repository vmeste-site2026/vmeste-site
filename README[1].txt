# Вместе — готовая основа сайта

## Что уже есть
- адаптивная главная страница;
- регистрация и вход через Supabase;
- профили;
- поиск по профилям;
- сообщения между пользователями;
- SEO title/description;
- robots.txt и sitemap.xml;
- счётчик профилей.

## Что нужно сделать для настоящего публичного сайта
1. Создать проект Supabase.
2. В SQL Editor выполнить `supabase_schema.sql`.
3. В Supabase Authentication включить Email/Password.
4. Открыть `app.js` и вставить URL проекта и anon key.
5. Загрузить файлы на хостинг и подключить домен.
6. Добавить сайт в Google Search Console и Яндекс Вебмастер.
7. Для статистики посещений подключить Google Analytics и/или Яндекс Метрику.

Важно: сейчас `onlineCount` не является настоящим онлайн-счётчиком. Для него нужен отдельный heartbeat/presence-механизм на сервере. Это можно добавить следующим этапом.
